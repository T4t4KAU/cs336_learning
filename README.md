# cs336_learning
A journey of learning CS336 and doing it's labs

## 协作模式/前言
* 本仓库建立目的在于互相帮助督促进行cs336的学习从而整个大模型有更加清晰的认知以及强化自己的实践能力，欢迎大家一起维护main也可以上传自己认为高质量的课程相关内容
* 学习方式为各自建立分支进行学习，作业实现，先做完作业的可以直接放入main，觉得其他人的实现有待优化的欢迎直接注释指出
* main放置高质量文档以及作业的参考实现方便其他同学进一步学习
* 有课程相关的优质homework和参考实现也可进入main
* 有实现好的组件或者模块也可放入main
* 有科研上的讨论性问题或者好的论文或者对论文的解读或者对就业的任何简介或者疑问或者对开源社区的优化思路都可放入main
* 对agentic/llm/infra/课程本身有任何问题欢迎提issue或者放入main一起讨论
* 有任何推荐的优质课程或者学习资源都可放入main或者提issue
